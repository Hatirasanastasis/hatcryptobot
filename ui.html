Quick start
  1. Start / Stop → Start demo.
  2. Watch the Dashboard. Trades also go to your phone (below).
  3. Change risk in Settings.
  4. Real money only after demo looks good: add keys, set a live budget, then Start LIVE.

      
Phone app
Use the dashboard on your phone while the PC runs the bot.
        Phone and PC must be on the same Wi-Fi. If Windows asks about network access, allow Private networks.
